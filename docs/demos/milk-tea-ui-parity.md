# 奶茶 UI 演示功能对照

更新：2026-10-17。只修改独立 HTML 演示，不改正式 Vue 页面、后端或配置。

## 设计边界

- 页面整合不等于功能裁减：高频经营常驻，低频功能移入详情窗口。
- 库存用横向三列小项，普通奶茶合并为底部一行；各款仍可打开配方详情。
- 工作详情包含当前班次、五种互动、次数与不可用原因、工资、雇佣状态和历史记录。
- 所有操作使用固定夹具，只修改页面内存。不得连接真实账号或把演示数据视为真实规则。
- 官方互动名称、描述、配方、等级门槛与雇佣时长参考仓库官方配置；未知结果不猜数值。

## 功能对照

| 原正式页面能力 | Demo 位置与处理 |
| --- | --- |
| 开店、改名 | 尚未开业状态、店名旁改名入口；保留名称校验 |
| 奶茶券、营业额、销售速度、喇叭 | 摘要、成长区、预估说明和库存下方工具入口 |

| 店铺升级、效果、奖励、等级预览 | 右侧成长区；顶部可切换可升级状态；等级预览展示 13 级 |
| 员工、时间、员工位、好友和实习员工 | 员工区及雇佣详情，单选时长、员工选择与不可用状态 |
| 当前兼职、雇主、特长、工资、下班时间 | 我的工作详情，上方摘要和班次进度 |
| 五种互动与确认、次数限制、结果 | 我的工作详情互动区；用完次数仍保留置灰选项 |
| 邀请好友雇佣 | 按用户确认移除工作中的邀请入口，网页无法操作；保留五种可用工作互动 |
| 允许被雇佣 | 我的工作开关，同步入口状态 |
| 工资领取 | 我的工作工资区及侧栏待领提示 |
| 历史兼职记录 | 我的工作下半区：店铺、雇主、起止、时长、最终工资、互动收益 |

| 分享快乐、领取日志 | 活动奖励底部入口；保留 QQ 原生能力提示 |
| 基金状态、条件、奖励、领取 | 成长基金详情；未购买不可领取，不增加购买付费基金入口 |

| 兑换数量、增减、最大、滑动、合计和确认 | 商品点击后进入独立确认视图，打开商品不会直接扣款 |
| 营业记录、各款售出、收益、雇员记录 | 营业记录详情，不再用自动执行日志代替营业记录 |
| 排行、更新时间、我的排名、分页、炫耀 | 排行详情；全部为示例玩家，炫耀保留原生提示 |
| 自动化状态与账号设置入口 | 详情展示 12 项，绿色右置圆点表示已开启，灰色左置圆点表示已关闭；同时提供文字、状态底色和总数，右侧摘要沿用同一表现；状态只读，保留账号设置入口 |
| 时间规则、刷新、加载、失败、无数据、结束 | 页头及顶部状态选择；失败不伪造零数据 |

## 演示与正式实现区别

本演示验证信息架构与交互，不是正式协议实现。奖励、基金、排名、材料批次、价格、记录等仅有代表性夹具；不保证包含真实账号的所有数据条目。演示页面明确标注数据来源边界。正式移植时必须沿用已有归一化数据、服务端金额、倍率、限额、状态、时间保护与动作校验，不能将这些夹具写入业务代码。

尚未模拟的真实服务行为包括改名冷却响应、完整开业礼包、每批变异果实的动态金币/产量、互动随机结果、实时计时与后台同步。入口和相应展示区域必须保留，正式版继续由原逻辑驱动。原生邀请/分享/领取日志不能误实现为网页直接操作。
